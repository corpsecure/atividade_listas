## Exercícios Lista

1. Crie um progrma que receba do usuario entradas numéricas inteiras e armazene-as em uma lista. Percorra os itens e conte quantos são pares e quantos são ímpares.
2. Combine duas listas separadas em uma única lista unificada.
3. Crie um programa que receba palavras inseridas pelo usuário e armazene-as em uma lista de strings. Identifique qual string possui o maior número de caracteres.
4. Crie um programa que declare uma lista L, a qual você pode preenchê-la manualmente. Em seguida, o programa deve calcular a média geométrica entre o menor e o maior elemento da lista L. Ao fim, o programa deve imprimir a média geométrica encontrada.
5. Uma turma de formandos está vendendo rifas para angariar
recursos financeiros para sua cerimônia de formatura. Construa um
programa para cadastrar os nomes das pessoas que
compraram a rifa. Ao fim, o programa deve sortear o ganhador
do prêmio e imprimir o seu nome.

#### Enviar o código da atividade para seu repositório no github.
#### Cada exercício deve estar em um código separado, sugestão de nome: _exercicio1_listas.py, exercicio2_listas.py e exercicio3_listas.py._
#### Enviar o link do seu repositório na atividade do classroom.
